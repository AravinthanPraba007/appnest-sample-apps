# Core Capability Lab — User Personas

## Primary persona

| Attribute | Description |
|-----------|-------------|
| **Role** | Internal engineer / platform QA |
| **Goal** | Quickly verify that file, DB, HTTP, schedule, and chain primitives work after install or config change |
| **Pain points** | Fragmented tests, unclear whether failures are app vs platform, no shared resettable state |
| **Context** | Uses the app inside the host product (SurveySparrow) as a full-page AppNest app |

## Secondary personas (if any)

- **App builder** — uses the lab as a **reference** for SDK patterns when starting a new integration.  
  *v1:* same UI and flows as primary; no separate persona-specific features.

## v1 focus

For v1 we are designing for: **internal engineer / platform QA**. Other roles are documented for future phases.
