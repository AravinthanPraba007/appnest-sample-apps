# SurveySparrow Contact CSV Export — User Personas

## Primary persona

| Attribute | Description |
|-----------|-------------|
| **Role** | SurveySparrow workspace administrator or marketing/ops user with access to contacts |
| **Goal** | Pull a filtered list of contacts and download only selected rows as CSV |
| **Pain points** | Bulk exports that include unwanted rows; manual cleanup in Excel; context-switching to external tools |
| **Context** | Works inside SurveySparrow daily; comfortable with tables, search, and simple exports |

## Secondary personas (if any)

- **Developer / integrator:** May install or configure the app once; not the primary daily user for v1.

## v1 focus

For v1 we are designing for: **the primary persona (admin / ops contact manager)**. Secondary roles are documented for future phases.
