# SurveySparrow Response Viewer — User Personas

## Primary persona

| Attribute | Description |
|-----------|-------------|
| **Role** | Product Manager / CX lead |
| **Goal** | Review survey results and feedback quickly without using APIs or scripts. |
| **Pain points** | No single place to list surveys and browse responses; reliance on technical team or manual API calls. |
| **Context** | Uses SurveySparrow; needs to inspect submissions and occasionally download backups for reporting. |

## Secondary personas (if any)

- **Developers:** Test SurveySparrow integrations; need a stable UI to verify responses.
- **Data Analysts:** Explore survey submissions; need pagination and backup download for offline analysis.

## v1 focus

For v1 we are designing for: **Product Managers and CX teams** as primary; developers and analysts as secondary. All roles benefit from survey list, response viewer, pagination, and backup download.
