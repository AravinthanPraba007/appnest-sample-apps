# SurveySparrow Response Viewer — User Personas

## Primary persona

| Attribute | Description |
|-----------|-------------|
| **Role** | Product manager / CX lead |
| **Goal** | Quickly see which surveys exist and browse their responses without using API tools. |
| **Pain points** | Manually calling APIs; no single place to list surveys and view responses. |
| **Context** | Uses SurveySparrow for feedback/NPS; needs to spot-check results and share with stakeholders. |

## Secondary personas (if any)

- **Developer:** Testing SurveySparrow integration; wants to verify survey list and response payloads without writing scripts.  
- **Analyst:** Exploring survey submissions; needs a simple paginated view to inspect answers.  
- **Customer experience team:** Reviewing feedback; wants minimal clicks to open a survey and scroll through responses.  

## v1 focus

For v1 we are designing for: **Product managers and CX teams** who need to list surveys and browse responses. Developers and analysts are supported by the same flows; advanced filters and export are documented for future phases.
