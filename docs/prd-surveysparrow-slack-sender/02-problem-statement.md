# SurveySparrow → Slack Response Sender — Problem Statement

## Problem

Teams using SurveySparrow for feedback must open the product to see new responses. There is no quick path to surface the latest answers in Slack where the team already works.

## Users affected

SurveySparrow users (admins, CS, PMs) who want ad-hoc visibility of recent survey responses in a Slack channel.

## Current gap / pain

Manual checking of SurveySparrow; copy-paste or custom scripts to get data into Slack.

## Why now

Reduces friction for “what did respondents say lately?” without building a full integration product.

## Desired outcome

From one screen: choose survey → paste webhook → send; Slack shows a readable block of the latest five responses.
