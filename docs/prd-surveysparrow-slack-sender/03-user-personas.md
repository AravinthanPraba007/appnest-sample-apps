# SurveySparrow → Slack Response Sender — User Personas

## Primary persona

| Attribute | Description |
|-----------|-------------|
| **Role** | SurveySparrow user (e.g. CS lead, PM) with access to API token and a Slack Incoming Webhook for a channel |
| **Goal** | Push the latest few survey responses to Slack on demand |
| **Pain points** | Switching tools to read responses; no simple “send to Slack” in v1 product flow |
| **Context** | Uses the app inside the host SaaS (Appnest); token configured once at install |

## Secondary personas (if any)

*None for v1.*

## v1 focus

For v1 we are designing for: **the primary persona** (on-demand sender). Other roles are documented for future phases.
