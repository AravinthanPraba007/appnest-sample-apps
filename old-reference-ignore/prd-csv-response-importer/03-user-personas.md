# CSV Response Importer — User Personas

## Primary persona

| Attribute | Description |
|-----------|-------------|
| **Role** | Customer success / operations or researcher who needs to bring external or legacy survey data into SurveySparrow. |
| **Goal** | Import CSV survey responses into a chosen survey without writing code or calling APIs manually. |
| **Pain points** | Manual API usage is error-prone; scripts require maintenance; no single place to map columns and see import results. |
| **Context** | Has SurveySparrow API key; has CSV exports from Google Forms, spreadsheets, or legacy tools. |

## Secondary personas (if any)

- **Developers:** Want a no-code import solution to offer to internal users.
- **Business analysts:** Consolidating survey responses from multiple sources into one survey.

## v1 focus

For v1 we are designing for: **the primary persona (customer success / researcher)**. Other roles are documented for future phases.
