# CSV Response Importer — Data Model

## AppNest storage

All persistent state must use the AppNest **$db** API. Types: `string`, `number`, `list`, `map`, `boolean`. Do not use in-memory state for cross-invocation data. See `appnest-tools/appnest-governance/02-sdk/05-SDK-Reference.md`.

---

## Core entities

| Entity | Purpose | Key pattern (e.g. for $db) | $db type | Notes |
|--------|---------|-----------------------------|----------|--------|
| import_run | One import run: metadata for history list and detail | `import_run_{{workspaceId}}_{{runId}}` | map | runId, surveyId, surveyName, runAt (ISO), timezone, submissionCreatedTime (ISO or null), totalRows, successCount, failedCount, errorDetails (JSON string or list), filePath (for $file), status (completed/partial/failed). |
| import_run_list | List of runIds per workspace for listing/pagination | `import_run_list_{{workspaceId}}` | list | Append runId on each new run; trim or paginate (e.g. last 100). |
| settings | Global (per workspace) timezone and default submission time | `settings_{{workspaceId}}` | map | timezone (IANA), defaultSubmissionCreatedTime (optional). |

## Storage keys

- **import_run_{{workspaceId}}_{{runId}}:** Map. runId is generated by backend (e.g. UUID or timestamp-based). Fields: runId, surveyId, surveyName, runAt, timezone, submissionCreatedTime, totalRows, successCount, failedCount, errorDetails, filePath, status, csvFileName (original name).
- **import_run_list_{{workspaceId}}:** List of runIds, newest first. Used by listImportRuns to resolve run metadata; optionally cap size (e.g. last 200) and drop oldest.
- **settings_{{workspaceId}}:** Map. timezone (string), defaultSubmissionCreatedTime (string or null).

## Sensitive data

- **Secrets:** SurveySparrow API key from **installation_params** only; never in $db.
- **PII:** CSV content stored in $file may contain PII (e.g. email). Access only via authenticated getImportRun / download; document retention and that files are PRIVATE. No PII in $db beyond optional csvFileName.

## File storage ($file)

| Path or pattern | Visibility | Operations used | Handler(s) | Notes |
|-----------------|------------|------------------|------------|--------|
| `imports/{{workspaceId}}/{{runId}}/upload.csv` | PRIVATE | write (during submitResponses), getDownloadUrl (in getImportRun) | submitResponses (write), getImportRun (getDownloadUrl) | One CSV per run; backend writes after generating runId; frontend sends CSV content in submitResponses payload (base64 or raw). |

- **Key format:** Paths are strings; workspaceId and runId from context/payload.
- **Visibility:** PRIVATE so only app backend can generate download URLs for authenticated users.

## External system data (if any)

- SurveySparrow holds survey and response data. This app stores only run metadata and the CSV file copy for history/audit. Idempotency/duplicate handling per 09-non-functional (e.g. best-effort; document if API supports created_at/submission time).
